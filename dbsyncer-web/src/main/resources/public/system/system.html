同步任务线程池 数据同步的核心执行器，负责将缓冲队列中的变更事件批量写入目标端

所有同步任务（Meta）共享此线程池，每个任务独享一个缓冲队列。
消费线程从队列中取出变更事件，按表名分区合并后批量执行 DML/DDL 写入。
线程数决定同时处理的同步任务并发能力；队列满时源端写入将阻塞。

日志线程池 异步写入系统操作日志，避免阻塞业务主流程

负责将操作日志、错误日志等异步持久化到存储。
所有日志写入任务共享此线程池，写入操作从业务线程剥离，不阻塞同步主流程。
线程数决定日志并发写入能力；队列满时新日志将被拒绝。

统计线程池 任务启动前的数据量统计，为全量同步提供进度基准

负责在全量同步启动前，统计各驱动（Mapping）下源表的总行数，为同步进度提供基准数据。
按任务唯一 ID 去重：同一任务重复提交时，旧任务将被终止并由新任务接管。
线程数决定同时统计多个驱动数据量的并发能力。
