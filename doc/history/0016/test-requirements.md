## 测试范围

### 后端功能测试

1. **LogVo 数据模型**
   - [ ] modelType 字段存在性和正确性
   - [ ] modelId 字段存在性和正确性（TableGroup 需关联父级 Mapping）
   - [ ] type 字段合并（原 LOG_TYPE 和 TYPE）
   - [ ] JSON 序列化/反序列化

2. **BaseServiceImpl.log() 统一方法**
   - [ ] ConfigModel 日志记录正确性
   - [ ] Mapping 日志记录正确性
   - [ ] TableGroup 日志关联到父级 Mapping
   - [ ] null 对象处理
   - [ ] 模型类型识别（CONFIG_MAPPING, MAPPING, TABLE_GROUP）

3. **MonitorServiceImpl.queryLog()**
   - [ ] 按 modelId 查询（必需参数验证）
   - [ ] 按 modelType 过滤
   - [ ] 按 type 过滤
   - [ ] 按 logLevel 过滤
   - [ ] 分页功能正常
   - [ ] performance: < 500ms

4. **MonitorServiceImpl.clearLog()**
   - [ ] 按 modelId 清空指定任务日志
   - [ ] 验证清空后数据为 0
   - 页签切换

2. **日志查询功能**
   - 关键字查询
   - 分页加载
   - 清空日志

3. **兼容性测试**
   - 全局监控页面日志查询不受影响
