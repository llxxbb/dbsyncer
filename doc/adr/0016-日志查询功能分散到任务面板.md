# ADR-0016: 日志查询功能分散到任务面板

## 状态

**Accepted** (2026-06-23)

## 上下文

当前日志查询功能在监控页面全局展示，无法按任务隔离查看日志。用户需要查看单个任务的日志时，无法过滤。

## 决策

### 方案选择

采用 **v2 方案**：使用 `model_type + model_id` 双字段替代单一 `mapping_id`。

**原因**：
1. 支持多类型日志（MAPPING, SYSTEM, CONNECTOR）
2. 查询更精准，避免不同实体类型混淆
3. 架构更清晰，符合单一职责原则

### 核心设计

**表结构**：
```sql
CREATE TABLE `dbsyncer_log` (
  `ID` varchar(64) PRIMARY KEY,
  `MODEL_TYPE` varchar(32) NOT NULL COMMENT '实体类型：mapping, system, connector',
  `MODEL_ID` varchar(64) NOT NULL COMMENT '实体 ID',
  `LOG_TYPE` varchar(32) NOT NULL COMMENT '日志类型：INSERT, UPDATE, DELETE, CONNECT',
  `LOG_LEVEL` varchar(10) COMMENT '日志级别：INFO, WARN, ERROR',
  `CREATE_TIME` bigint,
  `JSON` mediumtext
);
```

**后端接口**：
```java
// LogService 接口
void log(Map<String, Object> model, LogType logType, String msg);

// LogType 枚举
- 常规：INSERT, UPDATE, DELETE, COPY
- 任务：RUNNING, STOP, CLEAR, RESET, INCREMENT, FULLF
- 连接器：CONNECT
- 授权：UPLOAD, ACTIVATE, IMPORT, EXPORT

```

**MonitorService 接口**：
```java
Paging queryLog(Map<String, String> params);  // modelId 必填
String clearLog(Map<String, String> params);  // modelId 必填
```

**前端 Tab**：
- 任务编辑页新增"日志查询"Tab
- 支持类型、级别、关键字三维过滤
- 分页查询和清空日志功能

**TableGroup 处理**：
- TableGroup 日志关联到父级 Mapping
- 通过 `profileComponent.getMapping()` 获取映射关系

- ⏳ 验证：编译、功能测试、性能测试

## 验收标准

- [ ] 任务面板日志 Tab 可正常显示
- [ ] 支持按 modelId 过滤查询
- [ ] 支持按类型、级别过滤
- [ ] 清空日志只影响当前任务
- [ ] TableGroup 日志关联到父级 Mapping
- [ ] 查询响应时间 < 500ms

## 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| `ID` | 日志唯一 ID (雪花算法) | `1234567890` |
| `MODEL_TYPE` | 实体类型 | `mapping`, `system`, `connector` |
| `MODEL_ID` | 实体 ID | `abc123` |
| `LOG_TYPE` | 日志类型 (LogType 枚举值) | `INSERT`, `UPDATE`, `CONNECT` |
| `LOG_LEVEL` | 日志级别 | `INFO`, `WARN`, `ERROR` |
| `CREATE_TIME` | 创建时间戳 | `1234567890000` |
| `JSON` | 日志内容 | `"映射配置成功"` |
