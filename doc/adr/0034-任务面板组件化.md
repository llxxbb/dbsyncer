## 背景

在 `650ee1aa`（统一任务列表）中，任务列表的表格渲染被抽取为 `TaskList` 组件，供三个页面复用。但搜索、过滤、创建任务、卡片视图等功能仍散落在 `index.js` 中，无法被其它页面复用：

| 功能 | 当前位置 | 可复用性 |
|------|----------|----------|
| 表格渲染 + 行操作 | `TaskList` | ✅ 已复用 |
| 搜索框 + 过滤下拉 | `index.js` | ❌ 仅 index 页 |
| 卡片视图 | `task-card.html` (Thymeleaf) | ❌ 仅服务端渲染，不支持动态刷新 |
| 创建任务按钮 | `index.html` | ❌ 硬编码在页面中 |
| 视图切换（列表/卡片） | `index.js` | ❌ 仅 index 页 |

**异常任务页**和**数据源页**目前只用了 `TaskList`，但如果它们也需要搜索/过滤/卡片视图，要么重复实现，要么无法实现。

此外，`650ee1aa` 将 HTML 结构硬编码在 JS 字符串拼接中（违反前端规范"HTML 结构与 JS 逻辑分离"），已在本次重构中修正为 `<template>` 方案。

## 决策

采用四层组件架构，自底向上：

```
┌─────────────────────────────────────────────────────────────┐
│                       TaskPanel                              │
│  ┌─────────────────────────────────────────────────────────┐│
│  │ TaskToolbar（可选）                                      ││
│  │ [创建任务] [搜索...] [状态▼] [源▼] [目标▼] [列表][卡片] ││
│  ├─────────────────────────────────────────────────────────┤│
│  │ TaskList / TaskCardList（视图切换，内部联动）             ││
│  │ ┌─────────────────────────────────────────────────────┐ ││
│  │ │ 列表视图 或 卡片视图                                  │ ││
│  │ └─────────────────────────────────────────────────────┘ ││
│  └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

### 组件职责

| 组件 | 职责 | 不含 |
|------|------|------|
| **TaskPanel** | 容器编排、子组件联动、视图切换 | 数据获取、业务逻辑 |
| **TaskToolbar** | 搜索框、过滤下拉、创建按钮、视图切换按钮 | 搜索结果处理 |
| **TaskList** | 表格渲染、行操作（启动/停止/详情）、复选框、批量操作 | 数据获取 |
| **TaskCardList** | 卡片渲染、卡片操作 | 数据获取 |

### 核心原则

1. **数据获取在外** — 所有组件只接收 `setData()`，不发起 AJAX
2. **业务逻辑在外** — 创建任务、启动/停止的具体逻辑由外部回调决定
3. **UI 联动在内** — 搜索/过滤参数收集、视图切换、批量状态同步由 TaskPanel 内部处理
4. **按需裁剪** — 通过 `enableXxx` 开关控制功能，不需要的组件不渲染

### API 设计

```javascript
// ==================== index.html（全功能） ====================
var panel = new TaskPanel();
panel.init('#taskPanel', {
    // 功能开关
    enableSearch: true,
    enableFilter: true,
    enableCreate: true,
    enableCardView: true,
    enableCheckbox: false,

    // 回调：创建任务（外部处理）
    onCreate: function() {
        updateHash('/mapping/pageAdd?projectGroupId=' + ...);
    },

    // 回调：搜索/过滤（外部获取数据）
    onSearch: function(params) {
        // params = { keyword, state, sourceConnectorType, targetConnectorType }
        $.get('/index/searchMapping', params, function(resp) {
            panel.setData(resp.resultValue || []);
        });
    },

    // 回调：行操作
    onStart: function(id) { doAction(id, '/mapping/start?id=', '启动'); },
    onStop: function(id) { doAction(id, '/mapping/stop?id=', '停止'); }
});

// 外部设置过滤选项（connector 列表由页面获取后传入）
panel.setFilterOptions({ source: connectors, target: connectors });

// 外部设置数据
panel.setData(tasks);


// ==================== abnormalTasks.html（仅列表+批量） ====================
var panel = new TaskPanel();
panel.init('#taskPanel', {
    enableSearch: false,
    enableFilter: false,
    enableCreate: false,
    enableCardView: false,
    enableCheckbox: true,
    enableBatchStart: true,
    enableBatchStop: true,

    onStart: function(id) { ... },
    onStop: function(id) { ... },
    onBatchStart: function(ids) { ... }
});


// ==================== datasource.html（仅列表） ====================
var panel = new TaskPanel();
panel.init('#taskPanel', {
    enableSearch: false,
    enableFilter: false,
    enableCreate: false,
    enableCardView: false,
    enableCheckbox: false,

    onStart: function(id) { ... },
    onStop: function(id) { ... }
});
```

### TaskPanel 内部联动

| 用户操作 | TaskPanel 处理 |
|----------|----------------|
| 搜索框回车/点击 | 收集参数 → 调用 `onSearch(params)` |
| 过滤下拉变化 | 收集参数 → 调用 `onSearch(params)` |
| 点击 [创建任务] | 调用 `onCreate()` |
| 点击 [列表] | 隐藏卡片视图，显示列表视图 |
| 点击 [卡片] | 隐藏列表视图，显示卡片视图 |
| 点击行 [启动] | 调用 `onStart(id)` |
| 点击行 [停止] | 调用 `onStop(id)` |
| 点击行 [详情] | 默认打开详情页，可通过 `onDetail` 覆盖 |

### 备选方案与否决理由

| 方案 | 否决理由 |
|------|----------|
| 把搜索/过滤/创建全部塞进 TaskList | 职责混乱，从"列表组件"变成"页面控制器"；abnormalTasks/datasource 被迫配置一堆 `enableXxx: false` |
| 保留 Thymeleaf 渲染卡片视图 | 不支持动态刷新，与列表视图数据源不一致 |
| TaskPanel 内部处理数据获取 | 违反"数据获取在外"原则，组件无法适配不同 API |

## 影响

- **技术影响**：
  - 三个页面（index / abnormalTasks / datasource）统一使用 TaskPanel，搜索/过滤/卡片视图可跨页面复用
  - HTML 结构全部由 `<template>` 定义，JS 零字符串拼接
  - 组件职责清晰：展示 + 交互，不含数据获取
- **团队影响**：
  - 新增任务列表页面只需实例化 TaskPanel 并配置回调
  - 必须遵守前端规范（片段不变式、HTML/JS 分离、数据获取在外）
- **时间影响**：涉及 3 个模板文件 + 4 个 JS 文件 + 3 个页面改造，预计 1-2 天
