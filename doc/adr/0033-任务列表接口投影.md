## 背景

`650ee1aa`（统一任务列表）把 `IndexController` 的 `/index/mappingdata` 与 `/index/searchMapping` 从 `MappingJsonVo` 投影改为直接返回 `MappingVo`，使 `MappingVo.sourceConnector/targetConnector` 的完整对象图（`Connector → ConnectorConfig → DatabaseConfig{url, username, password}` 与 `List<Table>`）被 Jackson 原样序列化下发到浏览器。实测单次响应 97 KB，含明文数据库凭据与源库 209 张表名。

排查发现另外两个接口存在同构泄漏，且均早于 `650ee1aa`：

| 接口 | 引入提交 | 单次响应 | 含凭据 |
|------|---------|---------|--------|
| `GET /index/mappingdata` | `650ee1aa`（统一任务列表，**回归**） | 97,558 B / 4 行 | ✓ |
| `GET /index/searchMapping` | `650ee1aa`（同上，**回归**） | 97,558 B | ✓ |
| `GET /index/abnormalTasks/api` | `1dbdad34f`（ADR 20 实现） | 59,848 B / 2 行 | ✓ |
| `GET /mapping/getRelatedMappings` | `e2a2c4362`（`MappingRelatedVo` 保留完整 `ConnectorVo`） | 522,955 B / 20 行 | ✓ |

四个接口的响应体是同一个前端组件 `static/js/shared/task-list.js` 的唯一输入，因此可以收敛为**一个**投影 VO。

## 决策

**采用显式白名单投影 VO**：新建 `ConnectorBriefVo`（仅 `name` / `running` / `connectorType`）与 `MappingListItemVo`（`id` / `name` / `model` / `createTime` / `updateTime` / `meta` / `sourceConnector` / `targetConnector`），四个接口统一改用 `MappingListItemVo.from(MappingVo)` 工厂。删除仅被 `getRelatedMappings` 使用的 `MappingRelatedVo`（与 `MappingListItemVo` 仅差 `createTime` 一个字段）。

前端 `task-list.js` 同步调整：`conn.config.connectorType` → `conn.connectorType`（平铺到顶层，不再嵌套 `config`）。

### 备选方案与否决理由

| 方案 | 否决理由 |
|------|---------|
| 在 `DatabaseConfig` 上加 `@JsonIgnore` 屏蔽 `password` | `PreloadTemplate` 用 `JsonUtil.objToJson` 持久化配置，`@JsonIgnore` 会同时破坏存储序列化——保存连接器时密码字段被丢弃，等同于静默丢数据 |
| 复用既有 `MappingJsonVo`（仅 `id` / `model` / `meta`） | 会丢失 `name` / `createTime` / `updateTime` / 连接器信息，正好回退 `650ee1aa` 想要统一任务列表的初衷 |
| 保留 `MappingRelatedVo`，仅把 `config` 置空 | 留下两份几乎相同的 VO 形状，且依赖每个未来调用者记得手动 scrub，是隐式契约 |
| 全局脱敏 `/datasource/list` 与 `/datasource/get` | 数据源编辑页需要回填表单，需要独立设计「空密码保留原值」的往返语义，本次范围外 |

## 影响

- **技术影响**：
  - 四个接口响应体积下降 97%：`/mappingdata` 97 KB → 3.2 KB，`/abnormalTasks/api` 60 KB → 1.8 KB，`/getRelatedMappings` 523 KB → 17 KB；
  - 响应体中不再含 `password` / `username` / `jdbc:` 等明文凭据与源库表清单；
  - 前端字段形状变化（`config.connectorType` → `connectorType`）；
  - 新增 2 个 VO 类，删除 1 个 VO 类，4 个 Controller 方法改动各 1–3 行；
  - 代价：列表需要新字段时，VO 与工厂必须显式更新（白名单，fail-safe）。
- **团队影响**：新增任务列表类接口时，默认使用 `MappingListItemVo`，不要把 `MappingVo` 直接返回给浏览器。
- **时间影响**：1 天（含 Playwright 端到端验证）。
- **已知未覆盖**：`/datasource/list` 与 `/datasource/get` 仍返回完整 `Connector.config`（含明文密码），因为数据源编辑页需要回填表单。需要单独 ADR 设计「空密码保留原值」的往返语义。
