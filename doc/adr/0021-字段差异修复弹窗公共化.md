## 背景

ADR-0009 引入了字段差异修复弹窗（修复预览 + 确认执行），修复逻辑（`showFieldDiffFixPreview`、`renderFieldDiffFixPreview`、`executeFieldDiffFix`）和修复预览 Modal HTML 均写死在 `editTableGroup` 页面中。

`fieldDifferenceComponent.js` 作为公共差异展示组件，已在 `edit` 页面和 `editTableGroup` 页面复用，但"修复目标表"按钮在 `edit` 页面无响应（`onFixCallback` 未设置，修复预览 Modal 不存在于 `edit` 页 DOM 中），造成功能缺失。

## 决策

将修复预览弹窗及其逻辑下沉到 `FieldDifferenceComponent`：

1. **HTML 公共化**：修复预览 Modal 从 `editTableGroup.html` 移至 `fieldDifferenceModal.html` fragment
2. **JS 公共化**：修复预览/执行逻辑移入 `fieldDifferenceComponent.js`
3. **页面适配**：各页面通过 `showFixButton` 选项控制按钮显隐，通过 `fieldDiffConfigChanged` 事件统一通知刷新

## 影响

| 文件 | 变更 |
|------|------|
| `fieldDifferenceModal.html` | 追加修复预览 Modal 到 fragment |
| `editTableGroup.html` | 删除内联修复预览 Modal |
| `fieldDifferenceComponent.js` | 新增修复预览/执行逻辑，`show()` 增加 `showFixButton` 选项 |
| `editTableGroup.js` | 删除约 170 行修复相关代码 |
| `edit.js` | 新增 `fieldDiffConfigChanged` 监听，刷新差异列表 |

## 验收标准

1. `edit` 页面点击差异列 → 弹窗 → 点击"修复目标表" → 弹出修复预览 → 确认执行 → 差异列表刷新
2. `editTableGroup` 页面修复功能不受影响
3. `fieldDifferenceComponent.js` 的 `showFixButton` 选项为 `false` 时，隐藏修复按钮
